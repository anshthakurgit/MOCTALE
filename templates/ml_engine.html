01
Primary Key Dataset Merging ETL & Data Hygiene

Ingests tmdb_5000_movies.csv and tmdb_5000_credits.csv. Merging strictly on the unique primary key movies.id == credits.movie_id eliminates Cartesian cross-multiplication on duplicate titles (e.g. The Host, Batman), ensuring a clean, unpolluted 4,800-film catalog.

merged = movies.merge(credits, left_on='id', right_on='movie_id')
02
Missing Value Handling & Positional Index Reset Data Integrity

Filters films with null overview synopses and executes an immediate reset_index(drop=True). This ensures total synchronization between DataFrame positional index labels and matrix row coordinates, preventing out-of-bounds IndexError crashes.

df.dropna(subset=['overview'], inplace=True) df.reset_index(drop=True, inplace=True)
03
Entity Disambiguation & Token Atomicity Feature Engineering

Extracts plot overviews, genre designations, plot keywords, top-3 billed cast members, and the primary director. Spaces inside multi-word entities are stripped (e.g. Christopher Nolan → ChristopherNolan) to guarantee atomic semantic identity in the Bag-of-Words space.

tags = overview + genres_tokens + keywords_tokens + cast_tokens + director_tokens
04
Morphological Normalization (Porter Stemmer) Natural Language Processing

Iterates through every token in the synthesized corpus and maps inflected and derived words to their root morphological base using NLTK's Porter Stemmer algorithm (e.g., directing, directed, director → direct).

ps = PorterStemmer() tags = " ".join([ps.stem(word) for word in text.split()])
05
High-Dimensional Vectorization (CountVectorizer) Vector Space Modeling

Constructs a 5,000-dimensional vocabulary using Scikit-Learn's CountVectorizer(max_features=5000, stop_words='english'). Tokens that appear across multiple movies are indexed, producing a sparse vector $\mathbf{v} \in \mathbb{R}^{5000}$ for each film.

cv = CountVectorizer(max_features=5000, stop_words='english') feature_matrix = cv.fit_transform(df['tags']) # Shape: (4800, 5000)
06
Compressed Sparse Row (CSR) Optimization Memory Engineering

With $99.39\%$ of the vector space consisting of zeros, storing a dense array would consume over 185 MB of memory. Moctale serializes the feature space as a Compressed Sparse Row (CSR) matrix occupying only $295 \text{ KB}$ on disk and precomputes top-20 nearest neighbors in $1.3 \text{ MB}$.

scipy.sparse.save_npz('artifacts/feature_matrix.npz', feature_matrix)
07
Pairwise Directional Cosine Similarity Projection Geometric Ranking

Calculates the cosine of the angle $\theta$ between the query vector $\mathbf{u}$ and candidate vector $\mathbf{v}$. Scores range from $0.0$ (orthogonal; zero shared vocabulary) to $1.0$ (identical tag vector). The query movie is excluded, and the top-5 nearest neighbors are returned.

scores = cosine_similarity(query_vector, feature_matrix).flatten()

Theoretical Foundations of Content-Based Recommenders

A comparative analysis of collaborative versus content-based recommendation architectures, high-dimensional vector representations, and algorithmic trade-offs.

01

The Cold-Start Advantage

Collaborative filtering systems (e.g. Matrix Factorization, SVD, User-Item ALS) require dense interaction matrices. When a new film enters the database with zero user ratings, collaborative systems fail completely. Content-based filtering is immune to this constraint because the recommendation signal is intrinsic to the item's metadata profile.

02

Why Angular Distance Over Euclidean

Euclidean distance measures the physical length between two points ($\sqrt{\sum (u_i - v_i)^2}$), heavily penalizing films with longer synopses that naturally contain higher word counts. Cosine similarity normalizes vector lengths to unit hyperspheres, measuring strictly the orientation angle $\theta$ of thematic alignment.

03

Known Algorithmic Limitations

Content-based filtering tends toward over-specialization: it only suggests films that closely resemble the user's explicit query, offering limited serendipitous cross-genre discovery. Furthermore, it depends entirely on metadata quality—films with sparse overviews or obscure crews yield shallower mathematical vectors.

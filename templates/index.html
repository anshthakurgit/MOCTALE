    Technical Architecture

    How Moctale Generates Recommendations

    Moctale uses a pure Content-Based Filtering (CBF) machine learning pipeline. Rather than relying on volatile collaborative user ratings, each film is represented as a high-dimensional mathematical vector extracted from its textual narrative and artistic metadata.

    01

    Semantic Tag Synthesis

    We extract plot overviews, genre designations, plot keywords, top-3 billed cast members, and the primary director. Entity names are normalized into atomic tokens (e.g. ChristopherNolan) to prevent lexical collisions.

    02

    Stemming & Vectorization

    Every token is morphologically stemmed using the Porter Stemmer algorithm to reduce inflected words to their root forms. We then construct a 5,000-dimensional bag-of-words representation using Scikit-Learn's CountVectorizer with English stop-word filtration.

    03

    Cosine Similarity Projection

    To rank film proximity, we measure the directional cosine angle between the query vector and all 4,800 corpus vectors. The resulting scalar product yields exact similarity scores, with the top 5 nearest neighbors returned in real time.
